# Description
Giao diện website được phát triển bằng ReactTS

## Task
- Chức năng phát hiển lỗi chính tả
- Chức năng dịch văn bản tiếng Việt sang tiếng Anh
- Upload file văn bản (word, text)
- Lưu lịch sử các lần gọi request
- Thống kê rate limit của mô hình

## Run

```bash
cd \trans_fixer
```

```bash
npm install
```
```bash
npm run dev
```
